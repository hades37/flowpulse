# FlowPulse

基于 Excalidraw 的动态流程图编辑器。创建节点并用双端绑定的箭头连接，可以配置数据包数量和周期，播放演示，保存工程或导出图片和动画。

## 开发

```sh
npm install
npm run dev
npm test
npm run build
```

开发服务默认使用 5173 端口。浏览器本地自动保存当前场景；也可以下载 JSON 工程备份。

通过右侧“新建画布”可创建空白图。新建会替换当前的浏览器自动保存，可在确认窗口先保存当前工程。

## 使用说明

- 双击节点编辑文字，按住空格拖动画布；选择已绑定两端的箭头可调整动画。
- 选中连线可单独启停数据流，选中节点可单独启停该节点的涟漪、演示高亮和徽标；设置会随场景保存。关闭连线动画不会移除演示步骤。
- 点击右侧播放按钮打开讲解流程：新建多个流程，选择连线、调整步骤顺序并填写说明。播放支持暂停、上一步和下一步；自动演示仍按场景中箭头的顺序播放。流程不推断分支条件或并行执行。
- 分享链接将场景数据压缩在 URL 中，接收方可只读查看；较大的图会产生较长链接。
- PNG 导出完整静态图；GIF 和 WebM 录制当前视口，导出前可使用“适应内容”调整范围。WebM 依赖浏览器的录制支持。
- 曲线上的粒子轨迹基于曲线采样；手绘粗糙线条可能存在细微偏差。
