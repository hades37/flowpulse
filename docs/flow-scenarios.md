# 讲解流程：设计与范围

## 目标

在一张架构图上维护多个讲解场景。每个流程由用户选择并排序已有的双端绑定连线，为每个步骤添加说明；播放时突出当前连线和相关节点。无须把同一张图复制成多份。

## 交互

- 右侧“讲解流程”入口提供自动演示和自定义流程。新建时用当前连线初始化步骤，之后可以添加、删除、调整顺序和说明。
- 播放器支持暂停、继续、上一步、下一步、重播和退出。手动切换步骤会暂停自动播放。
- 连线被删除或解绑时，编辑器保留该步骤并要求重新选择；不能悄悄跳过并播放错误流程。
- 关闭某条连线的数据流动画仍保留其流程步骤；节点动画开关继续控制对应节点的效果。
- 选中普通箭头可切换直线与曲线，已有折线转折点保留。

## 数据与兼容

工程数据包含可选的 `flows` 数组：每个流程有 `id`、`name` 和有序 `steps`；步骤保存 `edgeId` 和 `description`。数据跟随自动保存、JSON 和只读分享链接。旧工程没有该字段时使用空流程列表，仍可自动演示。

## 后续

当前流程为串行步骤，不自动推断分支、并行、响应方向或循环条件；用户可通过创建多个流程表达不同路径。自动绕障、流程内条件及并行步骤另行设计。
